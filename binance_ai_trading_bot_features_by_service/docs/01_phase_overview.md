# Phase Overview — Binance AI Trading Bot

## Phase 0 — Project Foundation
Prepare the repository, service skeletons, Docker setup, shared contracts, and health checks.

## Phase 1 — Market Data + Dashboard MVP
Start by connecting Binance and displaying market data on the Dashboard and Market Watch pages.

## Phase 2 — AI Dataset + Feature Engineering
Create datasets, labels, technical indicators, and the feature schema.

## Phase 3 — AI Training + Inference
Train models, register models, activate models, and expose the inference API.

## Phase 4 — Strategy + Risk + Paper Trading
Create the decision flow from AI/rules → risk validation → order manager → paper trading.

## Phase 5 — Backtesting + Evaluation
Test strategies/models with historical data and use evaluation results before promotion.

## Phase 6 — Live Trading Safety
Add auth, audit logs, settings, alerts, and live safety guards.

## Phase 7 — Optimization + Automation
Multi-symbol, multi-strategy, notifications, auto retraining, and performance analytics.
